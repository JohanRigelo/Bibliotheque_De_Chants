# 🎵 Bibliothèque de Chants

Une application web permettant de gérer une bibliothèque de chants personnelle : ajout, modification, lecture et suppression de chants, avec système de listes personnalisées et affichage au format ChordPro (paroles + accords).

🔗 **Démo en ligne :** [bibliotheque-de-chants.vercel.app](https://bibliotheque-de-chants.vercel.app)

## ✨ Fonctionnalités

- Ajout, modification et suppression de chants (CRUD complet)
- Affichage des paroles avec accords intégrés (format ChordPro)
- Transposition des accords à la volée
- Création de listes de chants personnalisées

## 🛠️ Stack technique

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- ESLint

## 🚀 Installation et lancement en local

```bash
# Cloner le repo
git clone https://github.com/JohanRigelo/Bibliotheque_De_Chants.git
cd Bibliotheque_De_Chants

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

L'application sera accessible sur `http://localhost:5173` (port par défaut de Vite).

## 📦 Build de production

```bash
npm run build
```
